Student Information System

A simple Java console application that collects and displays basic student information while validating user input.

The project was built to practice Java fundamentals such as user input, variables, conditional logic, loops, and basic validation through a small student information workflow.

Features
Enter and display student information
Validate student age within a specified range
Enter and validate GPA values
Enter credit hours
Handle yes/no student status input
Classify the student's GPA based on its value
Concepts Practiced

Scanner · Variables · Data Types · String · int · double · if/else · while · Logical Operators · break · Input Validation · nextLine() after numeric input

Built as part of my Java learning journey to strengthen core programming fundamentals and practice handling different types of user input.
